プロジェクト概要

システム名
LoL チャンピオンピックツール
概要
League of Legends のゲーム中にチャンピオン選択フェーズ（ピック）を補助するWebツール。先出しピックおよびカウンターピックの2機能を提供する。
利用者
個人（作成者のみ）
利用場面
ゲームセッション中のチャンピオン選択フェーズ（約30秒以内での参照を想定）
利用環境
PCブラウザ（Chrome推奨）、LoLクライアントと並行表示
2

目的・背景

背景

League of Legends のチャンピオン選択フェーズでは、環境（メタ）に強いチャンピオンや相手チャンピオンに有利なカウンターピックを素早く判断する必要がある。 既存の統計サイト（lolalytics等）は情報量が多く、短時間での参照に適していない場面がある。 本ツールはシンプルなUIで「今選ぶべきチャンピオン」を即座に確認できる環境を提供する。

目的

  • ピック時間内（約30秒）に勝率上位チャンピオンを即座に確認できること
  • 相手チャンピオンに対して有利なチャンピオンをワンクリックで参照できること
  • Riot Games公式APIを活用したフルスタック開発のAI学習・技術習得
3

機能要件

3.1 先出しピック機能

要件ID優先度要件内容補足
FR-01 Must レーン選択（TOP / JG / MID / BOT / SUP） タブまたはボタンで選択
FR-02 Must 選択レーンの勝率上位チャンピオン一覧を表示 勝率・試合数を表示。上位20体を表示
FR-03 Must パッチバージョンフィルター 現行パッチをデフォルト選択
FR-04 Must ランク帯フィルター（全体 / Platinum+ / Diamond+ / Master+） デフォルト: Platinum+
FR-05 Should 地域フィルター（JP / KR / NA / EUW） デフォルト: JP
FR-06 Could Tier分類（S/A/B/C）でグルーピング表示 勝率に基づく自動分類。閾値：S ≥ 55% / A 53〜55% / B 51〜53% / C < 51%

3.2 カウンターピック機能

要件ID優先度要件内容補足
FR-10 Must レーン選択（TOP / JG / MID / BOT / SUP） 選択レーンの相手チャンピオンのみ表示対象
FR-11 Must 相手チャンピオン選択 検索ボックス＋アイコン一覧から選択
FR-12 Must 相手チャンピオンに対して勝率の高いチャンピオンを一覧表示 対戦勝率・試合数を表示。上位15体
FR-13 Must FR-03〜05 と同様のフィルター適用 パッチ・ランク帯・地域フィルター
FR-14 Should 相手チャンピオンの概要（勝率・ピック率）を表示 選択した相手チャンピオンの環境内強さを参考表示

3.3 データ収集・管理機能（バックエンド）

要件ID優先度要件内容補足
FR-20 Must Riot MATCH-V5 APIから試合データを収集 GitHub Actionsのバッチジョブで定期実行
FR-21 Must 収集データをリージョン・ランク帯・パッチで集計 集計済みデータのみDBに保存（生データは保存しない）
FR-22 Must バッチの実行ログをDBに記録 収集件数・ステータス・エラー内容
FR-23 Should パッチ更新時に自動で前パッチをアーカイブ gameVersionの変化を検知して自動切替

制約事項・前提条件

項目内容
Riot API キーDevelopment Keyを使用。有効期限24時間のため手動更新が必要。レート上限: 100 req/2分
Riot API 利用規約個人・非商用・学習目的での利用のため許容範囲内だが、公開・商用利用は不可
スキル上げ順Riot APIでは取得不可のため本ツールの対象外
データ更新頻度パッチ更新（約2週間ごと）のタイミングでバッチ再実行を手動トリガーまたはCronで対応
収集対象リージョン初期リリースはJP・KRの2リージョン
Riot Games Development APIキーは申請から最大2営業日で発行される。Production Keyへの移行は今回の目的外。

用語定義

用語定義
先出しピック相手チームがどのチャンピオンを選ぶか分からない状態で自チャンピオンを選択すること
カウンターピック相手チャンピオンが判明している状態で、そのチャンピオンに有利なチャンピオンを選択すること
Tierチャンピオンの環境内強さのランク。S > A > B > C の順
パッチRiot Gamesが約2週間ごとにリリースするゲームバランス調整バージョン（例: 14.10）
ランク帯プレイヤーのスキルランク。Iron / Bronze / Silver / Gold / Platinum / Emerald / Diamond / Master / Grandmaster / Challenger
レーンゲームマップ上のポジション。TOP（上）/ JG（ジャングル）/ MID（中）/ BOT（下）/ SUP（サポート）
PUUIDRiot Gamesが発行するプレイヤーの一意識別子
Data DragonRiot Gamesが提供する静的アセットCDN。チャンピオン情報・画像などを含む

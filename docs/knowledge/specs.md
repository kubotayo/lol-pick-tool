# 既存の仕様（設計書に書いていない動きや前提）

## 画面

- 先出しピック・カウンターピックの2画面は、どちらもクライアントコンポーネント（`'use client'`）で、開いたときに `/api/patches` を呼び、返った一覧の先頭（最新）のパッチを選ぶ
- トップページ（`app/page.tsx`）の下の「現在の設定」は固定の文字（`JP / Patch 14.21 / Diamond+`）で、実際の既定値（Platinum+）や、覚えた絞り込み条件とは連動していない
- 保存がないときの既定のレーンは、先出しピックが MID、カウンターピックが TOP

## ブラウザに保存するもの

- 絞り込み条件（レーン・ランク帯・地域）だけ。localStorage のキー `lol-pick-tool:filters`（仕様は 03 の 5章）
- 個人を特定する情報や、認証の情報は保存していない

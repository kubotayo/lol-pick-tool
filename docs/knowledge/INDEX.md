# ナレッジの索引

このプロジェクトの知識の置き場所。作業の開始時にこの索引を読み、関係するファイルだけを開く。

- ナレッジは設計書ではない。仕様の正は設計書（`docs/` 直下の HTML）で、ここには設計書に書かない前提・用語・過去の意思決定を書く
- 本文には今の内容だけを書く。経緯は `decisions/` に書く
- ファイルを足したら、下の表に1行足す
- プロジェクトをまたぐ知識（用語・業務ルール）は `~/.claude/knowledge/INDEX.md` を見る

| ファイル | 内容 | 読むとき |
|---|---|---|
| `specs.md` | 既存の仕様（設計書に書いていない動きや前提） | 既存の機能を変えるとき |
| `design-policy.md` | 設計方針 | 設計するとき |
| `decisions/` | 過去の意思決定（1件1ファイル） | 同じ論点を決めるとき |

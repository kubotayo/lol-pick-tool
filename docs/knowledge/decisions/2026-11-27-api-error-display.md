# API から取得できないときは、画面にその旨を表示する

- 日付: 2026-11-27
- 状態: 確定（表示を足すことは 2026-11-27、範囲と文言は 2026-11-28）
- 決めた人: 表示を足すことはユーザー（PR #42 の確認）。範囲と文言は、AI の仮決めをユーザーが 2026-11-28 にそのまま採用
- 関係する未確定事項: U-16（決定済み）・U-17（2026-11-28 に確定）（`docs/factory/remember-filters/open-items.md`）

## 決めたこと

- `/api/patches` を取得できない・空のときに、文言を表示する
- `/api/champions`・`/api/counter` を取得できないときも、同じように表示する
- 原因ごとには分けず、再試行のボタンも置かない

## 理由

- 取得できないと「読み込み中」のまま止まり、利用者には待てばよいのか壊れているのかがわからなかった
- 利用者ができることは読み込み直すことだけで、原因ごとに分けても行動が変わらない

## ほかの案と、選ばなかった理由

- パッチの取得だけ表示する: 3つの API の失敗の扱いを同じ場所（`lib/useApiList.ts`）で決めたので、分けるほうが手間がかかる
- 再試行のボタンを置く: 利用者は1人で、読み込み直しで足りる

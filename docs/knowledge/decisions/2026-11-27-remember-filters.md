# 絞り込み条件はブラウザに保存し、パッチは覚えない

- 日付: 2026-11-27
- 状態: 確定（2026-11-28）
- 決めた人: AI の仮決めを、ユーザーが 2026-11-28 にそのまま採用（PR #42 の確認）
- 関係する未確定事項: U-01・U-02・U-03（`docs/factory/remember-filters/open-items.md`）

## 決めたこと

- レーン・ランク帯・地域を、ブラウザの localStorage に保存し、次に開いたときに選んだ状態にする
- 先出しピックとカウンターピックで、同じ値を共有する
- パッチは保存せず、開くたびに最新のパッチを選ぶ

## 理由

- 利用者は1人で、アプリにログインの機能がない。サーバーや DB を変えずに実現できる
- パッチを覚えると、新しいパッチが出た後も古いパッチの数字を見続けることになる（01 FR-03 の「現行パッチをデフォルト選択」と食い違う）

## ほかの案と、選ばなかった理由

- URL のクエリに持つ: ブックマークはできるが、トップページから開くと消える
- DB に保存する: ログインの機能が要る（スコープ外）
- パッチも覚え、新しいパッチが出たら最新に戻す: 仕組みが増えるわりに、古いパッチを見たい場面が少ない

データフロー詳細

3.1 バッチ収集フロー（GitHub Actions）

1

最新パッチバージョン取得（Data Dragon）

APIキー不要の Data Dragon CDN から最新パッチを自動取得。
GET https://ddragon.leagueoflegends.com/api/versions.json
先頭要素 "14.21.1" を正規化 → "14.21"（先頭2セグメント）。環境変数 TARGET_PATCH の手動更新は不要。

2

プレイヤーシード取得

LEAGUE-V4 で Platinum以上のプレイヤーPUUIDを取得（対象リージョン・ランク帯ごと）

3

試合IDリスト取得

各PUUIDのMATCH-V5 /matches エンドポイントで直近の試合IDを取得。gameVersion の先頭2セグメントが TARGET_PATCH と一致するもののみフィルタ。

4

試合詳細取得 + リアルタイム集計

試合IDごとに詳細データ取得。生データは保存せず、取得直後にメモリ上で集計処理。レート制限ハンドラーが1200ms sleep を自動制御。

5

Supabaseへ UPSERT

champion_stats / counter_stats / item_build_stats を集計値で UPSERT（既存行は上書き更新）

6

ログ記録

collection_logs テーブルに収集件数・実行時間・ステータスを記録

3.2 フロントエンド参照フロー（ユーザー操作時）

1

ユーザーがレーン・フィルターを選択

ブラウザ上でレーン / パッチ / ランク帯 / リージョンを選択

2

Next.js API Route にリクエスト

クライアントが `/api/champions?lane=MID&patch=14.10&tier=platinum_plus®ion=JP` へ GET

3

Supabase から集計データ取得

API Route が Supabase SDK でクエリ。集計済みデータを win_rate DESC でソートして返却。

4

UI に表示

チャンピオンアイコン（Data Dragon CDN）と勝率・試合数を一覧表示。レスポンス目標: 1秒以内。

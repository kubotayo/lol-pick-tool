## OT-05 の判定と試合数の減少の調査（ブランチ `test/ot-05-collection-drop`）

### やったこと

- OT-05 を 06 v1.6.2 の判定で確かめ、合格を記入した（06 v1.6.3）。判定方法は 2026-11-12 に reviewer の3回目の再レビューで確認済み
- 試合数の減少を、run の全ログ・`scripts/collector.ts`・本番の DB（読み取りのみ）で調べた

### 調査の結果

- 大きく減ったのは、対象パッチが 16.22 から 16.23 に変わった run 44201000394（2026-11-17 23:38 UTC 開始）から。古いパッチの削除は 60,292行で、処理済みは 0件から始まった
- 16.22 の間にも 10,500 → 9,010 試合と約14%減っていた（1試合 1.79 → 2.08 秒）。原因は未解明
- 調べた11回の run はすべて時間上限 330分で終わり、取得失敗・時間切れの警告は 16.23 の初回の1件だけ
- 1試合にかかる時間（名簿の作成後からループ終了まで。430試合の回を除く）は、16.22 で約1.8〜2.1秒、16.23 で 3.70 → 2.86 秒
- 主な原因と考えられること（ログとコードからの推定。リクエスト数は記録していないので未計測）: パッチの切り替え直後は、各プレイヤーの新パッチの試合が少ない。未処理の古いパッチの試合が ID 一覧に含まれるプレイヤーでは、ID 一覧の取得と打ち切り用の1試合の取得が、集計できる試合の数に関係なくかかる
- 初回の 430試合は、以前から課題にある「パッチの当日は Data Dragon と試合のパッチがずれる」に当たると考えられる
- 16.23 の試合数（430試合の回を除く）は 5,108 → 5,252 → 5,602 → 6,026 → 6,597 と増えている。この増加が続くか、元の水準まで戻るかは分からない

### 決めたこと（とその理由）

- 調査だけで、コードは変えない。対応するかはユーザーが決める
- 02 の「1日約9,500〜12,700試合」の見込みは今回は直さない。減少への対応を決めるときに、実績とあわせて見直す

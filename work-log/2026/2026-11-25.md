### 決めたこと（とその理由）

- `~/Claude` のルールは全部消す（ユーザーの判断）。このプロジェクトのルールはプロジェクトの中にあるので、移動してもそのまま効く。`~/Claude/CLAUDE.md` に写すと、`~/Claude` の下のほかのプロジェクトにもこのプロジェクトのルールが当たるため、写さない
- コードの書き方は A案にした（ユーザーの判断）。要点だけを `coding.md` に移す。`app/`・`components/`・`lib/`・`scripts/` を扱うときだけ読み込まれるので、毎回読む量は増えない
- 今のコードと照らして、合わないものは移さなかった
  - 1行100文字まで: 100文字を超える行が多い（コメント以外の行にもある）
  - `import type` を最後のグループにまとめる: `type` を付けて同じ import に含めている箇所が多い
  - 複数行の末尾のカンマ: 確かめていないため
  - PR のスクリーンショット・本文の型・テストの書き方: 進め方は `pr-review` スキルと `test-spec.md` にあるため
- 今のコードで外れている箇所（`app/counter-pick/page.tsx` の `.then()`、モックを返す API Routes に `try/catch` がない）は、そのファイルを直すときに合わせる。今回は直さない
